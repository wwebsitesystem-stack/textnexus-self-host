Run Nexus on your own server.

A static front end that talks to Firebase from the browser. No build step, no application server.

Download the kit Read the full guide
This repository is the kit, not the website. The site files stay in the private TextNexus source. Copy the Self hosting folder into the root of your copy of those files, then follow the steps.

The seven steps

  1. Get the kit. Clone this repository or download the ZIP, then copy Self hosting into the root of your TextNexus site files.
  2. Start it. From the site root run docker compose -f "Self hosting/docker-compose.yml" up -d --build. Plain nginx uses Self hosting/nginx.conf.
  3. Open it. Go to http://localhost:8080. From another machine use the server address and allow port 8080.
  4. Publish the Firebase rules. Paste database.rules.json into Realtime Database → Rules and press Publish, or run firebase deploy --only database --project nexus-web-development-official.
  5. Allow sign-in. Add localhost and your domain under Firebase Authentication → Settings → Authorized domains.
  6. Add a domain and HTTPS. Proxy a TLS-terminating server to 127.0.0.1:8080 with Caddy, nginx and certbot, or a Cloudflare Tunnel. Add the hostname to Firebase's authorized domains.
  7. Update. Pull the site changes and run docker compose -f "Self hosting/docker-compose.yml" up -d --build again. Check that the workspace loads, Google sign-in returns to your domain, and https:// shows the padlock.

Quick start

# 1. from the site root, with the Self hosting folder in place
docker compose -f "Self hosting/docker-compose.yml" up -d --build

# 2. open http://localhost:8080

# 3. publish the Firebase rules
firebase deploy --only database --project nexus-web-development-official

Then add your hostname under Firebase Authentication → Settings → Authorized domains and put a TLS proxy in front before exposing the site to the internet.
